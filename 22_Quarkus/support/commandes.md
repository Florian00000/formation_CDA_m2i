- créer un projet quarkus

```bash
quarkus create app com.foo:bar:1.0
# bar = nom du projet ou artefact id / 1.0 pour le nom de la version 
# com.foo = org.example
```

- lancer l'app

```bash
quarkus dev
```

- ajouter une extension (pas besoin de recharger le pom.xml)
```bash
quarkus extension add nomExtension
```
